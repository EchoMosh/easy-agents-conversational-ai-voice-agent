Agent Settings Dialog Fix Summary

Issue Identified

The AgentSettings dialog was creating an invisible overlay that blocked all page interactions after closing. This was caused by improper state management where the component was mixing controlled and uncontrolled patterns.

  • The dialog's internal state wasn't syncing properly with the parent's state
  • The setOpen function was incorrectly assigned, causing state updates to fail
  • When the parent set showSettingsModal to false, the dialog's portal wasn't properly cleaned up

Solution Applied

The AgentSettings component has been updated to be fully controlled:

// Before - Mixed controlled/uncontrolled state const [internalOpen, setInternalOpen] = React.useState(false); const open = controlledOpen !== undefined ? controlledOpen : internalOpen; const setOpen = onOpenChange || setInternalOpen; // After - Fully controlled const open = controlledOpen ?? false; const setOpen = React.useCallback((value: boolean | ((prev: boolean) => boolean)) => { if (onOpenChange) { const newValue = typeof value === 'function' ? value(open) : value; onOpenChange(newValue); } }, [onOpenChange, open]);

How It Works Now

  1. The parent component (Header) maintains the dialog state with showSettingsModal
  2. When the user clicks the settings menu item, it sets showSettingsModal to true
  3. The AgentSettings component receives this as the open prop
  4. When the dialog needs to close (via X button, Cancel, or Save), it calls onOpenChange(false)
  5. The parent updates showSettingsModal to false
  6. The dialog properly unmounts and cleans up its portal

Testing Instructions

To verify the fix:

  1. Navigate to an agent's flow editor page
  2. Click the three dots (⋮) menu in the header
  3. Click "Settings" to open the dialog
  4. Close the dialog using any method (X button, Cancel, Save, or clicking outside)
  5. Verify that you can interact with the page normally (click buttons, hover over elements, etc.)
  6. The invisible overlay issue should no longer occur
